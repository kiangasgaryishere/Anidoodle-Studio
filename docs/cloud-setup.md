# Repeatable Codex Cloud setup

From `/workspace/Anidoodle-Studio`, run `bash scripts/setup.sh`. It checks Node >=20 and FFmpeg/ffprobe, runs upstream's frozen lockfile installation with optional packages omitted, creates a shared dependency link, selects installed Chromium when available, and performs an actual Canvas draw/read in Chromium. If Chromium is absent, it attempts the supported Playwright browser install. A missing FFmpeg or ffprobe is a hard setup failure, not a simulated success; this cloud base image already includes both. A different base image must supply them through its supported OS package setup.

Required npm dependencies: esbuild 0.25.12, three 0.170.0, playwright-core 1.63.0 and TypeScript 5.9.3. npm's --omit=optional avoids installing the optional Remotion/React stack. esbuild's verified platform installer runs normally. An ignored `node_modules/playwright` alias selects the pinned playwright-core API rather than the host's unrelated global Playwright 1.62.1.

Browser cache: `.cache/browsers`; on this image `.cache/browsers/chromium-0/chrome` points to `/usr/bin/chromium`. The engine's existing fallback browser discovery finds it. Browser builds can change rasterization: determinism here means repeated frames under the same recorded browser/runtime, not a guarantee across future Chromium updates. Run doctor and re-render after updates.

The original `file://` browser entry is blocked by managed Chromium policy. `scripts/cloud-transport.mjs` is loaded only for studio commands: it reads generated self-contained HTML beneath this checkout and supplies it with Playwright setContent. It leaves upstream source and offline-request assertions unchanged. An initial local-HTTP approach failed offline assertions and was replaced; no HTTP server is required. The adapter does not emulate external assets, modify request events, or relax browser policy.

Network: npm uses registry.npmjs.org (provided package-manager preset). Downloading Playwright Chromium additionally needs cdn.playwright.dev and its storage.googleapis.com distribution redirect; the first attempt was denied. These destinations are saved as optional fallback requirements in the environment draft; the tested system-browser path needs no browser download. GitHub PR creation needs api.github.com in addition to Git HTTPS access. Saving a draft does not apply or publish it.

No app credentials are required for silent drawing and encoding. Optional narration/Figma integrations need their own secure bindings and explicit task authorization. The sound pack (up to 373 MB) was not downloaded. Built-in synthesis requires no sample pack. Three.js is installed, but 3D is not validated by the 2D smoke scene. Remotion and Hyperframes are not installed or tested. WebM/APNG are supported upstream but not exercised here.

Exports and caches can consume substantial disk. Use a small worker count (2 tested); long films take proportionally longer. Keep important media in a durable archive/download as well as the cloud snapshot. Live browser processes are ephemeral; only dependency/filesystem state belongs in a published environment. There are no persistent studio services.
